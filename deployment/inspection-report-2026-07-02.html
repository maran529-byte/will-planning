🚨 P0 —— 一上来就要炸的三个硬伤

已修 P0-1: H5 根路径被反代到 SEO 主站

症状: curl h5.aiwill-planner.cn/ 返回的 HTML 字节大小与主站完全一致(MD5 相同),用户在主站点了"开始规划→"、"在 H5 开始"、"立即绑定账号"等按钮后看到的还是 SEO 首页,转化漏斗首步断流。

根因: nginx 配置在 /deployment/mainland-server/nginx.conf 的 location = / 块,直接 try_files /index.html 而不区分 host。

修复: 在 location = / 顶部加 if ($host = h5.aiwill-planner.cn) { return 301 https://h5.aiwill-planner.cn/doc-type; },PC 域名保持原行为。同时 src/components/LegalFooter.tsx 的"移动端"按钮从 h5.aiwill-planner.cn 改为 h5.aiwill-planner.cn/doc-type。

已修 P0-2: 登录弹窗的 OAuth 回调是 404

症状: 弹窗脚本硬编码 https://h5.aiwill-planner.cn/wechat/oauth?state=PC_LOGIN&return=...,实测 404。

根因: Next.js App Router 下 /wechat/oauth 路由根本不存在(/wechat/bind 有,但 /wechat/oauth 是另一回事)。

修复: 新增两个文件:

  • src/app/wechat/oauth/page.tsx — server component,负责 metadata + Suspense 包装
  • src/app/wechat/oauth/OAuthClient.tsx — client component,调 /api/wechat/prepare-oauth → 拼 authorize URL → 自动跳转;5 秒未跳显示手动按钮

已修 P0-3: 底部免责声明重复

症状: 主页底部挨着 3 段高度雷同的免责声明(套餐下方 + 内容性质说明 + 💡 关于我们的内容)。

修复: 删除两处 index.html(/index.html 和 /deployment/mainland-server/index.html)里 hero 区下方的"💡 关于我们的内容"重复段(line 637-640)。底部内容性质说明 + 数据安全 + ICP 备案保留。

已修 P0-4: 登录/注册按钮行为一样

症状: 顶部"登录"和"注册"两个按钮 href 都是 #login-modal。

修复: 两个 index.html 顶部按钮加 data-intent="login" / data-intent="register" 属性,JS click handler 读取后传给 show({intent})。意图为 register 时弹窗副标题切换为"使用微信账号快速注册",并把 intent 信息一路传到 OAuth 跳转 URL,后续可扩展"邮箱注册"折叠面板默认展开。

已修 P0-5: 删 /orders "模拟订单数据" + /orders /account 增"立即登录"按钮

修复:

  • src/app/orders/page.tsx line 283 删掉"这是模拟订单数据..."段
  • src/app/orders/page.tsx line 124-148 未登录卡片加"立即登录(邮箱密码)"主按钮 + "绑定微信账号"次按钮
  • src/app/account/page.tsx line 89-108 NotLoggedInView 同样加 2 个按钮
