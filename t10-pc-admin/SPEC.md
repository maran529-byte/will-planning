## 3. 页面详细设计

### 3.1 概览仪表盘
```
结构: 顶部统计卡片(4列) + 中部双栏(图表+待办) + 底部最近契约列表
统计卡片:
  - 契约总数 / 本月新增 / 待签署 / 已完成
  - 图标 + 数字 + 标签 + 环比变化(箭头)
图表区:
  - 契约趋势图 (近30天折线图)
  - 饼图: 各状态契约占比
待办事项:
  - 待签署列表 (5条) + 查看更多
最近契约:
  - 表格形式 (名称/状态/创建时间/操作)
  - 查看全部链接
```

### 3.2 契约管理
```
页面结构:
  - 顶部: 页面标题 + 新建按钮 + 批量操作
  - 筛选栏: 状态筛选 | 日期范围 | 搜索框
  - 内容区: 数据表格

表格列:
  - Checkbox | 契约名称 | 契约类型 | 状态 | 签约方 | 创建时间 | 操作

操作:
  - 查看 | 编辑 | 下载PDF | 删除

分页:
  - 底部居右
  - 显示: 共 X 条 | 每页 Y 条 | 第 Z/N 页
  - 支持跳转
```

### 3.3 契约创建/编辑页
```
布局: 左侧表单区(70%) + 右侧预览区(30%)，可切换全屏预览
表单字段:
  - 基础信息: 契约名称、类型(下拉)、有效期(日期范围)
  - 签约方: 可添加多个，表单形式
  - 条款内容: 富文本编辑器
  - 附件: 上传组件
预览区:
  - PDF 预览
  - 实时更新
操作:
  - 保存草稿 | 预览 | 提交审核
```

### 3.4 模板管理
```
页面结构:
  - 顶部: 页面标题 + 新建模板按钮
  - 筛选: 模板分类 | 状态
  - 内容: 卡片网格 (3列)

模板卡片:
  - 缩略图
  - 模板名称
  - 分类标签
  - 使用次数
  - 操作: 编辑 | 复制 | 删除
```

### 3.5 签约方管理
```
页面结构:
  - 顶部: 页面标题 + 添加签约方按钮
  - 筛选: 类型(企业/个人) | 状态
  - 内容: 数据表格

表格列:
  - 签约方名称 | 类型 | 联系人 | 手机号 | 契约数量 | 状态 | 操作

详情抽屉:
  - 右侧滑出
  - 基本信息 / 契约记录 / 操作日志
```

### 3.6 合规检测
```
页面结构:
  - 顶部: 上传文件区域 (拖拽上传)
  - 检测流程: 步骤条 (上传 → 检测中 → 完成)
  - 结果展示: 通过/不通过 + 问题列表
  - 建议: 修复建议列表

检测结果:
  - 通过: 绿色徽章 + 通过信息
  - 不通过: 红色徽章 + 问题列表 (可折叠)
  - 每条问题: 条款位置 + 问题描述 + 修复建议
```

### 3.7 审计日志
```
页面结构:
  - 顶部: 日期范围选择器 + 操作类型筛选 + 用户筛选 + 搜索
  - 内容: 数据表格

表格列:
  - 时间 | 用户 | 操作类型 | 操作内容 | IP地址 | 结果

详情:
  - 点击行展开或弹窗显示完整JSON

导出:
  - 支持导出 CSV/Excel
```

页面结构:

## 4. 组件规范

### 4.1 Button
```
变体: primary | secondary | outline | ghost | danger
尺寸: sm(32px) | md(36px) | lg(40px)
状态: default | hover | active | disabled | loading
图标: 支持左/右图标
圆角: 6px
```

### 4.2 Input
```
类型: text | password | number | textarea
状态: default | focus | error | disabled
特性: 前缀图标 | 后缀图标 | 清空按钮 | 错误提示
高度: 36px (单行) / 自适应 (多行)
```

### 4.3 Select
```
类型: 单选 | 多选
特性: 搜索过滤 | 远程搜索 | 支持新建
状态: default | focus | error | disabled
```

### 4.4 Table
```
特性:
  - 支持排序 (点击列头)
  - 支持筛选 (列内下拉)
  - 支持多选 (Checkbox)
  - 支持列宽拖拽
  - 支持固定列 (左侧/右侧)
行高: 52px
表头: 背景 #F8FAFC + 字体加粗
```

### 4.5 Modal
```
类型: 对话框 | 抽屉
对话框: 居中 + 白色背景 + 圆角 8px + 遮罩 rgba(0,0,0,0.5)
抽屉: 从右滑入 + 宽度 480px/640px/800px
```

### 4.6 Badge/Tag
```
类型: 状态标签 | 分类标签
状态颜色映射:
  - 草稿:   #64748B (gray)
  - 待签:   #F59E0B (orange)
  - 签署中: #3B82F6 (blue)
  - 已签:   #16A34A (green)
  - 已拒绝: #DC2626 (red)
  - 已过期: #94A3B8 (light gray)
```

### 4.7 Card
```
背景: #FFFFFF
圆角: 8px
阴影: sm
内边距: 16px/20px
```

### 4.8 Breadcrumb
```
分隔符: /
最后一级: 加粗
可点击: 悬停显示下划线
```

### 4.9 Pagination
```
样式: 简洁分页
显示: 共X条 | 每页Y条 | < 1 2 3 ... N >
跳转: 支持直接跳转到某页
```

### 4.10 Form
```
布局: 纵向列表 | 网格布局 (2列)
标签: 左对齐，宽度 120px
校验: 实时校验 + 提交校验
错误: 字段下方红色提示
```

## 5. 状态设计

### 5.1 加载状态
- 骨架屏 (Skeleton) 用于表格和卡片
- Spinner 用于按钮操作和局部加载
- 进度条用于文件上传

### 5.2 空状态
- 统一空状态插画 (仓库图标)
- 文案 + 操作按钮
- 区分不同场景 (无数据/无权限/网络错误)

### 5.3 错误状态
- 全局错误提示 (顶部固定)
- 表单错误提示 (字段下方)
- 网络错误/服务器错误页面

### 5.4 成功反馈
- Toast 提示 (2s 自动消失)
- 操作成功后刷新列表

## 6. 响应式策略

### 6.1 断点
```
sm: 640px   (平板竖屏)
md: 768px   (平板横屏)
lg: 1024px  (小屏笔记本)
xl: 1280px  (标准桌面)
2xl: 1536px (大屏桌面)
```

### 6.2 侧边栏折叠
```
≥1024px: 默认展开
<1024px: 默认收起 (图标模式)
<768px: 侧边栏隐藏 (汉堡菜单)
```

### 6.3 表格响应
```
≥1280px: 完整列
1024-1279px: 隐藏次要列
<1024px: 卡片列表模式
```

## 8. 技术实现要点

### 8.1 前端技术栈
- React 18 + TypeScript
- 状态管理: Zustand / Redux Toolkit
- 路由: React Router v6
- UI 组件: Ant Design / Element Plus / 自定义组件
- 图表: ECharts / AntV
- 表单: React Hook Form + Zod
- HTTP: Axios + React Query

### 8.2 目录结构
```
src/
├── api/              # API 接口封装
├── components/       # 通用组件
│   ├── common/       # Button/Input/Table 等
│   └── layout/       # Layout/Sidebar/Header 等
├── pages/            # 页面组件
├── hooks/            # 自定义 Hooks
├── store/            # 状态管理
├── utils/            # 工具函数
├── styles/           # 全局样式
└── types/            # TypeScript 类型定义
```

### 8.3 性能优化
- 代码分割: 按路由懒加载
- 列表虚拟滚动: 大数据量表格
- 图片优化: WebP + 懒加载
- 缓存策略: SWR / React Query
