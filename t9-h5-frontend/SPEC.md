# T9-H5 详细设计规范

## 1. 设计语言

### 1.1 色彩系统
```
主色 (Primary):     #2563EB (蓝色 - 信任/专业)
次色 (Secondary):   #059669 (绿色 - 合规/成功)
强调色 (Accent):    #F59E0B (橙色 - 提示/警示)
背景色 (Background):#F8FAFC (浅灰白)
卡片背景:           #FFFFFF
文字主色:           #1E293B
文字次色:           #64748B
边框色:             #E2E8F0
错误色:             #DC2626
成功色:             #16A34A
```

### 1.2 字体规范
```
字体族: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
标题 H1: 28px / 700 / 1.2
标题 H2: 22px / 600 / 1.3
标题 H3: 18px / 600 / 1.4
正文:   16px / 400 / 1.5
小字:   14px / 400 / 1.5
```

### 1.3 间距系统
```
基础单位: 4px
xs: 4px   | sm: 8px   | md: 16px  | lg: 24px  | xl: 32px  | 2xl: 48px
```

### 1.4 圆角
```
小: 6px  | 中: 8px  | 大: 12px  | 全圆: 9999px
```

### 1.5 阴影
```
sm: 0 1px 2px rgba(0,0,0,0.05)
md: 0 4px 6px rgba(0,0,0,0.1)
lg: 0 10px 15px rgba(0,0,0,0.1)
```

## 2. 移动端布局

### 2.1 顶部导航
```
高度: 56px
背景: #FFFFFF
底部边框: 1px solid #E2E8F0
内容: 左侧返回/Logo + 中间标题 + 右侧操作

```
高度: 64px (含安全区域)

## 3. 页面详细设计

### 3.1 登录页
```
布局: 居中单列
内容:
  - Logo (居中, 64x64)
  - 标题: "aiwill-planner"
  - 副标题: "合规契约生成平台"
  - 手机号输入框 (+86 前缀)
  - 验证码输入框 + 获取按钮 (60s 倒计时)
  - 登录按钮 (主色, 圆角 8px, 高度 48px)
  - 底部: "登录即表示同意《用户协议》和《隐私政策》"
```

### 3.2 首页/概览
```
顶部导航标题: "首页"
内容:
  - 欢迎卡片 (用户名称 + 今日日期)
  - 快捷操作入口 (4 列网格)
    · 创建契约
    · 契约列表
    · 模板中心
    · 合规检测
  - 最近契约 (最近 3 条，Card 形式)
  - 统计数据 (待签署/已签署/草稿数量)
```

### 3.3 契约列表页
```
顶部: 搜索框 + 筛选按钮
筛选: 状态标签横向滚动 (全部/草稿/待签/已签/已拒绝)
列表: Card 列表
  Card 内容:
    - 契约名称 (单行截断)
    - 签约方信息
    - 状态 Badge
    - 创建时间
    - 操作按钮 (...)

分页: 下拉加载更多 / 分页器
```

### 3.4 契约创建页 (向导式)
```
步骤条: 顶部横向步骤指示 (1. 基础信息 → 2. 条款详情 → 3. 签约方 → 4. 预览确认)
表单内容:
  Step 1: 契约名称、契约类型(下拉)、有效期
  Step 2: 动态表单字段 (根据类型加载)
  Step 3: 签约方信息 (可添加多个)
  Step 4: PDF 预览 + 确认提交

底部: 上一步 / 下一步 / 保存草稿 按钮
```

### 3.5 契约详情页
```
顶部: 返回按钮 + 标题 + 操作按钮 (...)
状态 Banner: 显示当前状态及颜色
内容:
  - 基本信息卡片
  - 条款内容 (可展开/折叠)
  - 签约方列表
  - 审计日志 (时间线形式)
底部: 操作按钮 (根据状态显示: 签署/拒绝/下载PDF)
```

## 4. 组件规范

### 4.1 Button
```
变体: primary | secondary | outline | ghost | danger
尺寸: sm(32px) | md(40px) | lg(48px)
状态: default | hover | active | disabled | loading
图标: 支持左/右图标
```

### 4.2 Input
```
类型: text | tel | number | password
状态: default | focus | error | disabled
特性: 清空按钮 | 密码显隐 | 错误提示
```

### 4.3 Card
```
背景: #FFFFFF
圆角: 12px
阴影: sm
内边距: 16px
```

### 4.4 Badge
```
颜色映射:
  草稿:   gray
  待签:   orange
  已签:   green
  已拒绝: red
```

### 4.5 Modal/Drawer
```
移动端: 从底部滑入的 Drawer
圆角: 顶部 16px
遮罩: rgba(0,0,0,0.5)
```

## 5. 状态设计

### 5.1 加载状态
- 骨架屏 (Skeleton) 用于列表和卡片
- Spinner 用于按钮操作
- Progress 用于文件上传

### 5.2 空状态
- 统一空状态插画
- 文案 + 操作按钮

### 5.3 错误状态
- Toast 提示 (2s 自动消失)
- 错误页 (网络错误/服务器错误)

### 5.4 表单验证
- 实时验证 (onBlur)
- 提交时整体验证
- 错误信息显示在字段下方

---

## 6. 技术实现要点

### 6.1 性能优化
- 图片: WebP 格式 + Lazy Load
- 代码分割: 按页面/路由
- 缓存: SWR 策略
- 预加载: Next.js Link prefetch

### 6.2 PWA 支持 (可选)
- manifest.json
- Service Worker
- 离线页面

### 6.3 监控
- Vercel Analytics
- 错误上报 (Sentry)
