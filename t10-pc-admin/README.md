# T10: PC管理后台

## 概述

PC 管理后台是 aiwill-planner 平台的 Web 端管理控制系统，提供完整的租户管理、契约管理、模板管理、用户权限管理等功能。

## 设计风格

参考 T9 H5 设计规范，保持色彩系统和组件风格一致：

- 主色: `#2563EB` (蓝色)
- 成功色: `#16A34A`
- 警告色: `#F59E0B`
- 背景色: `#F1F5F9`
- 侧边栏: `#1E293B` (深灰)

## 主要功能

### 1. 概览仪表盘
- 统计数据卡片 (契约总数/本月新增/待签署/已完成)
- 契约趋势图表 (近30天)
- 状态占比饼图
- 待办事项列表
- 最近契约列表

### 2. 契约管理
- 契约列表 (支持搜索/筛选/排序)
- 契约创建/编辑 (向导式表单)
- 契约详情查看
- PDF 下载
- 批量操作

### 3. 模板管理
- 模板列表 (卡片/列表视图)
- 模板创建/编辑
- 模板分类管理
- 模板使用统计

### 4. 签约方管理
- 签约方列表
- 签约方添加/编辑
- 签约方详情抽屉
- 关联契约查看

### 5. 合规检测
- 文件上传检测
- 检测结果展示 (通过/不通过)
- 问题列表及修复建议

### 6. 审计日志
- 操作日志查询
- 多条件筛选
- 日志详情查看
- 导出功能

### 7. 系统管理

#### 用户管理
- 用户列表
- 添加/编辑/禁用用户
- 密码重置

#### 角色权限
- 角色列表
- 权限配置
- 角色分配

#### 租户管理 (超级管理员)
- 租户列表
- 租户创建/编辑
- 套餐管理
- 额度配置

#### 系统设置
- 基本设置
- 邮件/短信配置
- 合规规则管理

## 权限设计

### 角色定义

| 角色 | 说明 |
|------|------|
| 超级管理员 | 系统全部功能，租户管理，系统配置 |
| 企业管理员 | 本租户全部功能，用户管理，角色配置 |
| 操作员 | 契约创建/编辑，模板管理，查看统计 |
| 查看者 | 仅查看数据，导出报表 |

### 权限矩阵

详细权限矩阵见 `SPEC.md` 第 7 章。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **UI 组件库**: Ant Design 5
- **状态管理**: Redux Toolkit / Zustand
- **路由**: React Router v6
- **图表**: ECharts
- **表单**: React Hook Form + Zod
- **HTTP**: Axios + React Query
