## 1. 服务器配置（回调 URL + Token + EncodingAESKey）

公众号与 HK Vercel 通信的唯一入口。

### 1.1 生成 Token 和 EncodingAESKey

在 **本地终端** 执行（不要在公众号后台生成，要预先知道）：

```bash
# Token: 32 位字母数字
openssl rand -base64 24 | tr -d '/+=' | cut -c1-32
# 示例输出: K8jL3nP9qR2sT5vW7xY0zA4bC6dE8fG

# EncodingAESKey: 43 位字母数字
openssl rand -base64 32 | tr -d '/+=' | cut -c1-43
# 示例输出: a1B2c3D4e5F6g7H8i9J0k1L2m3N4o5P6q7R8s9T0u1V2w
```

把两个值**先保存**到本地密码管理器（1Password / Bitwarden），稍后要填到两处。

### 1.2 公众号后台填写

1. https://mp.weixin.qq.com → 「设置与开发」→「基本配置」
2. 「服务器配置」卡片，点击「修改配置」：

| 字段 | 值 |
|---|---|
| **URL** | `https://h5.aiwill-planner.cn/api/wechat/mp-callback` |
| **Token** | （上一步生成的 32 位） |
| **EncodingAESKey** | （上一步生成的 43 位） |
| **消息加解密方式** | 「明文模式」（个人订阅号用明文足够，不要选兼容/安全模式增加复杂度） |

3. 点击「提交」→ 弹出"提交成功"对话框。
4. **此时不要点"启用"** —— 先在 Vercel 配置环境变量再启用。

### 1.3 Vercel 环境变量

Project → Settings → Environment Variables，**新增 4 个**：

```
WECHAT_MP_TOKEN        = <上面生成的 Token>
WECHAT_MP_AES_KEY      = <上面生成的 EncodingAESKey>
WECHAT_MP_APP_ID       = wx30fe5cd917eb2e7a
WECHAT_MP_APP_SECRET   = <新重置的 AppSecret>
```

Scope 选 Production + Preview。改完点 Save → 触发 Redeploy（Deployment → ⋯ → Redeploy）。

### 1.4 验证 URL 联通

Vercel 部署完成后，回到公众号后台，点击「启用」按钮。

公众号会发一个 GET 请求到 URL：
```
GET /api/wechat/mp-callback?signature=xxx&timestamp=xxx&nonce=xxx&echostr=hello
```

`src/app/api/wechat/mp-callback/route.ts` 的 GET handler 应该返回 200 + `echostr` 文本。

公众号页面应显示「启用成功」。

**自检命令**（手动验证签名校验逻辑）：
```bash
# Token 替换成你的
TOKEN="K8jL3nP9qR2sT5vW7xY0zA4bC6dE8fG"
TIMESTAMP=$(date +%s)
NONCE="test123"
ECHOTR="hello-world"
SIGNATURE=$(printf "%s%s%s" "$TIMESTAMP" "$NONCE" "$TOKEN" | sha1sum | cut -d' ' -f1)
echo "Generated signature: $SIGNATURE"

# 故意给错 echostr 看是否 401
curl -i "https://h5.aiwill-planner.cn/api/wechat/mp-callback?signature=$SIGNATURE&timestamp=$TIMESTAMP&nonce=$NONCE&echostr=$ECHOTR"
# 期望: 200, body 为 "hello-world"
```

## 2. 业务域名 / 网页授权域名 / JS 接口安全域名

三个域名配置都在同一处：「设置与开发」→「公众号设置」→「功能设置」。

### 2.1 业务域名（用于网页中调用 JS-SDK）

| 字段 | 值 |
|---|---|
| 域名 | `aiwill-planner.cn` |
| | `www.aiwill-planner.cn` |
| 备注 | 主站，业务域名（一行一个） |

验证方式：把腾讯给的 TXT 记录 `mPaaEqrDxxx` 加到 Cloudflare DNS。
（如果是「已验证域名」直接复用即可。）

⚠️ 业务域名限制**不能带协议头**，且**不能填 IP**。

### 2.2 网页授权域名（OAuth 跳转）

OAuth 流程里，redirect_uri 的域名必须在这里登记。

| 字段 | 值 |
|---|---|
| 域名 | `h5.aiwill-planner.cn` |

**关键点**：
- 网页授权域名 = `redirect_uri` 的 **host 部分**
- 公众号后台会以这个域名为前缀，校验 `redirect_uri`
- 此处**只能填 1 个**（个人订阅号限制）

### 2.3 JS 接口安全域名（可选）

仅当你需要 `wx.config` 调 JS-SDK（如分享卡片、扫一扫）时填：

| 字段 | 值 |
|---|---|
| 域名 | `h5.aiwill-planner.cn` |

当前架构**暂时不调 JS-SDK**（OAuth 已够用），可跳过。后续要加再回填。

### 2.4 验证

配置后 5 分钟生效。可在 H5 任意页控制台跑：


- 关注后自动回复（用户首次关注时发一次）

- 关键词自动回复（指定关键词触发）

### 4.1 关注后自动回复

「设置与开发」→「自动回复」→「关注后自动回复」：

```

👉 <a href="https://h5.aiwill-planner.cn/questionnaire">立即起草</a>
👉 <a href="https://h5.aiwill-planner.cn/wechat/bind">绑定账号</a> 查订单、收通知

```

订阅号**纯文本 + 链接**够用，无法加图片（订阅号无素材管理）。

### 4.2 关键词自动回复

「设置与开发」→「自动回复」→「关键词自动回复」→「添加规则」：

| 关键词 | 匹配方式 | 回复内容 |
|---|---|---|
| `订单` | 全匹配 | 📋 查订单：<a href="https://h5.aiwill-planner.cn/orders">点击查看</a>\n如未绑定账号请先<a href="https://h5.aiwill-planner.cn/wechat/bind">点此绑定</a> |
| `价格` | 全匹配 | 💰 三档套餐：\n• 简易草稿 ¥19.9\n• 标准生成 ¥999\n• 律师审核 ¥4699\n详情：<a href="https://h5.aiwill-planner.cn/?action=pricing">查看价格</a> |
| `备案` | 全匹配 | 🏛️ 备案信息：沪ICP备2026020925号-1\n<a href="https://beian.miit.gov.cn/">工信部查询</a> |
| `帮助` | 全匹配 | 📖 使用帮助：<a href="https://aiwill-planner.cn/faq">FAQ</a>\n或回复【人工】联系客服 |
| `人工` | 全匹配 | 💬 客服 9:00-21:00，<a href="https://h5.aiwill-planner.cn/?action=contact">在线表单</a>，或邮箱 service@aiwill-planner.cn |
| `绑定` | 全匹配 | 🔗 <a href="https://h5.aiwill-planner.cn/wechat/bind">点击绑定</a> 公众号与网站账号 |

> **注意**：这些关键词也由 HK Vercel 的 `/api/wechat/mp-callback` 处理（POST XML），
> **双通道并存**：
> - 公众号后台的关键词回复是**显式**配置（10 分钟生效）
> - Vercel 的处理是**动态**（可读数据库返回订单信息）
>
> 两者都启用时，**腾讯优先返回后台配置的文本**（不走 Vercel），
> 但 Vercel 仍会记录 `last_user_interaction_at` 开启 48h 客服窗口。
>
> 建议：**生产期让 Vercel 全权处理**（删后台关键词），订阅号后台只留「关注后自动回复」。

## 7. 故障排除

| 症状 | 原因 | 解法 |
|---|---|---|
| 启用服务器配置失败：token 错误 | Token 与 Vercel env 不一致 | 两处都打开对比，逐字符核对 |
| 启用失败：URL 超时 | HK Vercel 冷启动慢 | 在 Vercel 加 cron 保活，或选 vercel-functions-us-east-1 区域 |
| OAuth 跳到「redirect_uri 域名与后台配置不一致」 | 网页授权域名没填 | 补填 `h5.aiwill-planner.cn`，等 5 分钟 |
| 用户收不到客服消息 | 超过 48h 窗口 | 让用户先在公众号发条消息，或在 H5 内点任意按钮（系统会调 `recordUserInteraction` 模拟） |
| 菜单点击报「该公众号提供的服务出现故障」 | redirect_uri 不是 https | 全部强制 https，http:// 直接拒 |
| 收到大量重复消息 | 公众号后台与 Vercel 都处理关键词 | 二选一：保留 Vercel（推荐），删后台关键词 |
