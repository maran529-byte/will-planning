# 家有所爱 · 编辑政策 (Editorial Policy)

最后更新: 2026 年 7 月 3 日
适用范围: 知识中心 / 幸福指南 / 文书模板 / FAQ / 工具对比 / 方法论 等所有公开内容

一、编辑团队

本站内容由 家有所爱工作室 编辑组 整理, 经家事与财富传承方向的 专业人士通读。编辑组成员均接受过法律基础知识培训, 了解《民法典》婚姻家庭编、继承编的核心条款。

二、内容来源

  1. **法律法规**: 以《中华人民共和国民法典》(2021 年 1 月 1 日施行) 为核心依据
  2. **司法解释**: 最高人民法院发布的婚姻家庭 / 继承相关司法解释
  3. **实务经验**: 整理自家事律师、公证员的公开讲座、普法文章
  4. **用户反馈**: 来自公众号、家有所爱用户群的真实使用反馈

三、编辑流程

每篇内容上线前, 经历以下步骤:

阶段负责方周期输出 ------------ 选题编辑组1 天选题单 初稿编辑3-5 天5000-8000 字 事实核查另一编辑1 天核查清单 专业人士通读外聘专家2-3 天修订意见 修改定稿编辑1 天终稿 排版上线前端0.5 天公开页

四、内容原则

4.1 准确性

  • 法条引用必须可溯源至现行法规
  • 案例描述必须匿名化处理
  • 数字 / 金额标注口径与时间

4.2 客观性

  • 不夸大产品效果
  • 不掩盖风险 (例如: 模板为草稿, 不构成法律意见)
  • 复杂情况必须建议咨询持牌律师

4.3 实用性

  • 优先回答「用户下一步该做什么」
  • 配真实可下载的模板 (PDF / Word)
  • 关键节点附 FAQ 与交叉链接

五、更新机制

  • **法条变更**: 法律法规修订后 30 天内完成内容更新
  • **用户反馈**: 收到 3 条以上同类反馈即触发内容审查
  • **重大调整**: 涉及婚姻家庭编司法解释修订等, 启动专项更新
