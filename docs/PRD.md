## 1. 产品概述 (Product Overview)

### 1.1 愿景 (Vision)

成为中国家庭最值得信赖的 **"AI + 律师" 双引擎人生规划平台**——用科技守护爱与责任，让每一份对家人的牵挂都成为可执行、可传承、可验证的法律安排。

### 1.2 使命 (Mission)

- **降低门槛**：把一份原本需要 2000-10000 元律师费、3-7 天时间完成的婚姻/遗嘱文书，缩短到 **30 分钟在线自助 + ¥19.9 起**。
- **提高质量**：AI 草稿 + 专业律师审核 + 公证指引三层流水线，避免模板下载导致的法律漏洞。
- **保护合规**：在中国大陆 ICP 合规与海外服务可用性之间取得工程化平衡（双部署架构）。
- **赋能生态**：让法律从业者获得合规获客与远程接单的工具，让内容博主获得高客单价的合规带货产品。

### 1.3 目标用户 (Target Users)

| # | 角色 | 中文 | 一句话画像 |
|---|------|------|-----------|
| 1 | 普通用户 | 拟稿者 | 30-65 岁、有家庭资产、想自己生成或购买专业文书 |
| 2 | 律师 | 审核者 | 婚姻家事 / 继承方向执业律师、寻找远程案件与兼职收入 |
| 3 | 博主 | 推广者 | 抖音 / 小红书 / 微信情感 / 婚姻法律类 10-200 万粉 KOC |
| 4 | 管理员 | 运营者 | 平台运营、客服、法务、审核 |

### 1.4 服务范围 (Service Scope)

**6 大文书类型**（已上线）：
- 婚姻协议书 (`marriage`) — 婚前明确婚后财产与权利义务
- 婚内财产协议 (`marital-property`) — 约定婚姻存续期间财产归属
- 离婚协议 (`divorce`) — 子女抚养、财产分割、债务安排
- 子女抚养协议 (`child-custody`) — 抚养费、探视权
- 赠与协议 (`gift`) — 房产、财产赠与公证文书
- 遗嘱 (`will`) — 遗产分配、继承人指定、医疗意愿

**3 大定价档位**（已上线）：
- **AI 专属版** ¥19.9 — 问卷 + AI 草稿 + PDF 下载
- **律师护航版** ¥999 — AI 草稿 + 律师 30 分钟视频审核 + 签署指引
- **家庭年度版** ¥4699/年 — 全家族规划 + 年度律师顾问

**多渠道流量入口**：
- 大陆静态站品牌展示 (`aiwill-planner.cn`) → CTA 跳 Vercel Global
- 抖音 / 视频号博主推广码 → 直达 H5
- 自然搜索（百度长尾词 + Google 海外）
- 微信生态（小程序、公众号跳转，Day+5 阶段）

### 1.5 商业模式 (Business Model)

| 收入来源 | 单价 | 目标占比 | 说明 |
|----------|------|----------|------|
| AI 专属版零售 | ¥19.9 | 60% | 流量漏斗顶端、低决策门槛 |

| **禁止虚假宣传** | 严禁"100% 有效""必过"等极限词 | 文案审核 + 法务巡检 |
| **数据加密** | 客户端 → Vercel → Supabase 全程 HTTPS (TLS 1.3) | 全栈强制 |
| **微信支付** | 商户号需企业资质，0.6% 手续费，二清合规 | 接入前法务审批 |
| **数据出境** | 微信 OpenID / UnionID 不可导出至境外 | 数据脱敏 / 单独库 |
| **海外备案** | Vercel 域不在大陆 ICP 管辖，按所在地法律 | 法律咨询 |

### 6.2 数据隐私合规

| 数据类型 | 存储 | 保留期 | 用户权利 |
|----------|------|--------|----------|
| 身份证号 | Supabase.encrypted_column | 文书签订后 5 年 | 可查询、可删除 (软删) |
| 手机号 | Supabase + 加密 | 用户账户存续期 | 可变更、可注销 |
| 微信 OpenID | Supabase | 用户账户存续期 | 可注销即清除 |
| 资产信息 | Supabase (行级 RLS) | 用户主动删除即清 | 仅本人可见 |
| 草稿内容 | Supabase + Object Storage | 90 天后压缩归档 | 可下载、可删除 |
| 审计日志 | 不可变日志 (append-only) | 7 年 | 不可删 (合规要求) |

### 6.3 律师执业合规

- 律师入驻必须上传: **执业证书 (PDF) + 身份证 + 律所证明**
- 律师平台展示必须显式标注: 「执业证号：XXXX」
- 律师审核意见必须显示: 「以上意见仅供参考，不构成对您的法律代理」
- 律师禁止在平台外引流客户: 用户与律师建立委托关系后, **应脱离平台** (避免平台承担代理责任)
- 律师分润应缴纳个人所得税, 平台代扣代缴 (T+15)

### 6.4 支付合规

- 微信支付 / 支付宝: 营业执照 + ICP 备案 + 法人身份证
- 严禁"二清": 所有资金流必须经过持牌支付机构
- 单笔超过 ¥1000 律师版需风控: 实名认证 + 视频验证
- 退款必须原路返回, 不接受现金/转账退款

### 6.5 网信 / 工信部配合

- 网信 ICP 调查表 (大陆域): 经营内容填"婚姻/遗嘱文书模板智能生成参考服务"，**不**填"AI 服务"
- 备案变更: 每次功能重大变更需 7 日内提交变更申请
- 应急: 详见 `aiwill-planner_合规手册.docx` 第五篇 5 个时间窗

## 9. 风险与缓解 (Risks & Mitigations)

| # | 风险 | 等级 | 影响 | 缓解策略 |
|---|------|------|------|----------|
| R1 | **网信认定大陆站 = 实际承担 AI 中转** | 高 | 备案吊销 + 罚款 10 万 | 大陆 nginx 零 proxy_pass，Vercel 域独立运营 |
| R2 | **微信支付商户号审批不通过** | 中 | 收入阻断 | 同时申请支付宝；早期用收款码 / 银行转账过渡 |
| R3 | **律师执业责任纠纷** | 中 | 法律赔偿 | 强制免责声明 + 律师资质审核 + 平台责任切割 |
| R4 | **AI 草稿质量争议** | 中 | 退款潮 + 口碑崩盘 | "AI 草稿不具备法律效力" 文案 + 律师升级路径 + 退款规则 |
| R5 | **博主虚假宣传 / 引战** | 中 | 平台信誉受损 | 素材包审核 + 内容巡检 + 严重违规关停 |
| R6 | **Supabase 免费版超额** | 低 | 服务停摆 | 升级到 Pro ($25/月)；监控用量 |
| R7 | **MiniMax API 涨价 / 不稳定** | 中 | 生成失败 | 多供应商备份 (DeepSeek / 智谱) + fallback 模板 |
| R8 | **Vercel 域被 GFW 屏蔽升级** | 中 | 海外用户流失 | 保留大陆静态站作为入口；h5 子域备份 |
| R9 | **用户隐私数据泄露** | 高 | 罚款 + 口碑 | RLS + 加密 + 审计日志 + 最小权限原则 |
| R10 | **MySQL / Postgres 切换问题** | 低 | 微服务停摆 | 详见 FIX_PLAN.md Step 3 (切回 Postgres) |
